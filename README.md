# Projeto QA - Gestão de Testes com Jira

## 📋 Descrição

Este projeto apresenta a documentação completa de um processo de QA utilizando Jira como ferramenta de gestão.

## 🎯 Entregáveis

- ✅ Workflow de desenvolvimento e ciclo de vida do bug
- ✅ 2 User Stories detalhadas
- ✅ Mind-map da User Story de Login
- ✅ 2 Casos de teste Step-by-Step
- ✅ 2 Casos de teste BDD (Gherkin)

## 🛠️ Ferramentas Utilizadas

- Jira Software
- Git/GitHub
- Draw.io (Mind-map)
- Markdown/Gherkin
